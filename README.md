# 博士、何年目。 — Doctoral Life (Prototype v0.1)

日本の博士課程を題材にした、イベント駆動型ライフシミュレーターの**動作する試作版**。

- **単体HTML版**: `../doctoral-life-play.html` をダブルクリックするとブラウザで遊べます。ネット接続・サーバー不要。
- **ソース版**: `index.html` をブラウザで開いても動きます。アプリのコードは `src/` の4ファイルに分割。
- **ビルド**: `node tools/build.mjs`
- **テスト**: `node --test tests/*.test.cjs`

## 同じ初期条件から100通りの未来を分析

開始時の初期条件・ゲーム中の「100回分析」から、同じ人物・大学・教授・初期業績を固定して100回の完全オート人生を実行できます。結果画面には学位取得・標準年限内修了・論文採択数分布・DC1/DC2（申請した試行が分母）・終了までの期間を表示します。結果はゲーム独自の仮定によるシミュレーションであり、実際の博士課程統計ではありません。現在のセーブは変更されず、再実行すると新しい乱数系列で集計します。

`seed` / `profileSeed` は初期条件用、`episodeSeed` はその後のイベント／査読／採用などの抽選用です。明示的に両方を渡したときだけ、人生を完全再現できます。旧セーブは継続可能ですが、乱数列の分離は新規人生・再挑戦から適用されます。

## 今入っている機能

- DC1を知っていれば M2・4月から、知らなければ D1・4月から開始
- 分野 / 大学類型 / 地域 / 指導教員 / 家庭援助 / パートナー / 修士時代の業績を抽選
- 月単位の選択と状態更新：研究、執筆、資金申請、労働、相談、休養
- DC1、DC2、RA、学内博士支援への応募、数か月後の選考結果
- 投稿論文の査読キュー（Accept / Revision / Reject）
- 研究分野や教授タイプなどの条件で発生する物語イベント
- D3末の学位要件判定と1年間の延長、仮のキャリア抽選
- ブラウザ内セーブ、JSONログ出力、同一乱数シードでのリプレイ

## アーキテクチャ

```
index.html / styles.css  UIの枠・スタイル
src/ui.js               DOMの描画と操作 / セーブ / JSONエクスポート
src/data.js             人物属性・仮パラメータ・引用メタデータ
src/events.js           条件付きイベント定義（データ駆動）
src/engine.js           状態遷移 / 時間 / 確率抽選 / 予約キュー / 学位判定
tools/build.mjs         単一HTMLへの梱包
tests/engine.test.cjs   基本ルールの回帰テスト
```

ゲーム状態はシリアライズ可能なプレーンJSONです。イベント定義は `id`, `chance`, `conditions`, `choices` を備えます。`effects` は `{research: 8, morale: -3}` のような汎用の状態差分です。専門的なイベント（DC申請/採択、査読結果など）は `engine.js` 側の `kind` ハンドラが担当します。

### イベントを増やす

`src/events.js` の `random` 配列に以下のような定義を追加します。

```js
{
  id: 'experiment_delay',
  category: 'research',
  title: '実験装置のメンテナンス',
  description: '予約していた測定が延期された。',
  tone: 'negative',
  source: 'story',
  chance: .05, // 仮の月当たり確率（統計値ではない）
  cooldown: 9,
  conditions: {fields:['materials'],minMonth:0},
  choices: [
    {label: '別の解析を進める',detail: '原稿 +6',effects:{draft:6}},
    {label: '復旧を待つ',detail: '気力 +5',effects:{morale:5}}
  ]
}
```

イベント出典の分類： `public_rule`（公式ルール）、`candidate_dataset`（将来接続可能）、`story`（体験談型の創作）、`hypothetical`（モデル上の仮定）。

## 重要：現状は**統計シミュレーターではない**

研究分野と大学の重み、採択確率、生活費、RA枠、論文査読、教授の性質、学位要件、進路に至るまで**定量的な数字はすべて仮定**です。公式制度の申請時期・対象学年のみ参考にしています。実在大学ごとの修了規定を再現していません。現段階でのランダム抽選を日本の博士課程学生全体の代表サンプルとみなさないでください。

公的ソース候補：
- [JSPS 2027年度 特別研究員募集要項](https://www.jsps.go.jp/j-pd/pd_sin.html)
- [JSPS 申請資格、支給経費、採用期間](https://www.jsps.go.jp/j-pd/pd_oubo.html)
- [文科省 学校基本調査 2025年度](https://www.e-stat.go.jp/stat-search/files?layout=dataset&tclass1=000001236922&tclass2=000001236923&tclass3=000001236931&toukei=00400001&tstat=000001011528)

## 次の開発手順

1. **学位要件を実データ化**：各研究科の履修要件 / 論文要件と年次ルールをバージョン付きで登録。
2. **学生分布を実統計化**：分野 × 入学年度 × 大学 × 地域のマージナル分布をe-Stat/NIAD-QEから取り込み、観測できない相関は仮定として明示。
3. **資金の正確な要件**：DC、SPRING、RAの採択と併給条件を年度別に設定。DCの採択率は分野別・年度別の公式集計で較正。
4. **イベント根拠の整理**：体験談を種類の参考にし、発生率はアンケートや時間経過データから別途推定。
5. **コホート検証**：10万試行程度で、年度別の学位取得時期・就職先・経済状況・奨学金取得状況を比較し、確率モデルを較正。

## 既知の簡略化

- 分野の4分類、大学4類型、教授3類型だけを実装しています。実在の大学・研究室ではありません。
- M2〜D3をモデル化。博士4年制や社会人博士、休学等は未実装。
- 学位審査は論文数と進捗だけの簡略判定で、学位申請・予備審査・公聴会などは未実装。
- RA、SPRING、DCの併用制限は簡略モデルです。実制度と相違する可能性があります。
- 博士後のキャリアは仮の候補からランダム選択するだけです。
- 教授・家計・研究分野などの設定はシミュレーション上のフィクションで、客観的な評価を意図していません。
- 金銭管理は月あたり万円、借入は簡略化されており、税・社会保険・学費等を厳密には扱っていません。

## 公開実測統計（初期条件レポート）

`src/reference-stats.js` に JASSO 2024（経済支援受給割合）、NISTEP 博士人材追跡調査（2012年度修了者の発表論文数）、JSPS 科研費 2025（研究種目別新規採択件数・直接経費平均）、NISTEP定点調査2018（研究室・研究グループの大学種別平均構成）を**出典・対象集団付きで収録**しています。

公開統計は固定スナップショットです（オンライン自動取得ではありません）。初期ゲーム値は未較正で、実統計による百分位順位を意味しません。母集団と測定項目の相違を含む各値の再確認方法は [docs/REFERENCE_DATA.md](docs/REFERENCE_DATA.md) を参照してください。


### スタート時のゲーム内相対ステータス

最初の条件レポートで、「生活資金」「研究実績」「Grant環境」「研究室規模」の相対スコアとS〜Dランクを表示します。比較対象は同じ研究分野・M2/D1開始時点でゲームの抽選ルールから生成した**仮想学生1,024人**です。ゲームのエンタメ要素であり、現実の博士課程学生における分位・偏差値ではありません。下部の公的統計参考グラフはこれとは独立しています。詳細は `docs/INITIAL_REPORT.md`。

## 最終結果の相対ランク（ゲーム内比較）

プレイ終了時に、同じ初期プロフィールから完全オートで100回試行した架空の人生を比較母集団として、論文数・終了時の現金・累積借入のランクと分布、在籍期間の分布を表示します。在籍期間は学位未取得を含むため順位化しません。100回分析画面にも元の初期ステータス（ゲーム内の仮想学生1,024人との比較）を表示します。

初期ランク（仮想学生1,024人）と最終ランク（同条件のオート100試行）は別の母集団です。後者は戦略を固定したシミュレーション上の条件付き結果であり、実際の博士号取得率・所得分布を示しません。

## 最終結果の実統計との重ね合わせ

最終結果と100回分析の各ビューで、完全オート100試行と文部科学省／NISTEPの公表分布を緑・金色の棒で並べて表示します。修業年限（7分野切替）、学位取得、論文発表本数の3種類が対象です。調査集団・統計の定義はゲームと一致せず、比較・参考のための表示です。貯金・借入については現実の同一定義の分布を把握できていないため実測値を重ねていません。定義・出典・制約は [docs/REAL_WORLD_COMPARISON.md](docs/REAL_WORLD_COMPARISON.md) を参照。
