# Reference statistics / 実測統計のデータ契約

このリポジトリの `src/reference-stats.js` は、日本の公的機関による公表値の**手動確認済み固定スナップショット**です。外部 API へのオンライン接続や擬似乱数による補完は行いません。掲載値は表示用の観測参照資料であり、ゲーム初期値・抽選確率を較正したものではありません。

### 再検証と更新の手順

1. 各一次資料の表・調査対象・単位・注釈を確認する（必ず出典と年次を記録）。
2. 実測値を `src/reference-stats.js` に更新する。数値から派生する検証条件が変更された場合は `tests/initial-report.test.cjs` も変更理由を記す。
3. `node --test tests/*.test.cjs` とブラウザ表示を検証する。
4. 新しい資料がデータ項目を含まない場合は「データなし／比較不可」を表示し、正規分布・均等分布で埋めない。

### 将来の実測パーセンタイル

本当に「同年代の何パーセンタイルか」を表示するには、同じ研究分野・学年・集計期間・査読業績定義の個票／度数分布が必要です。今回の公表資料では条件がそろわないため、パーセンタイルは計算しません。過去のゲーム用抽選重み `[60,30,10]` と研究室予算レベルの `[33,33,34]` は「観測分布」として表示しません（ゲーム機構そのものの抽選は維持）。
