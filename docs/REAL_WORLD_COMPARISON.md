# 最終結果の実統計との参考比較

ゲーム内の同一初期プロフィールに基づく完全オート100試行と、公的機関の別の母集団・調査時点による結果を **同じカテゴリに並べて** 可視化します。これはモデルの妥当性検証・較正ではなく、定義の違いを体験する情報表示です。

## 使用データ

- **在籍期間**：文部科学省『大学院関連参考資料集（令和6年4月25日時点）』p.38「標準修業年限からの超過年別割合」（出典：令和5年度学校基本調査、令和4年度博士課程修了者等）。[原資料](https://www.mext.go.jp/content/20240604-mxt_koutou02-000033844.pdf)。標準年限3年の課程で、満期退学者を含み、編入学者を除外する。7学科系統別の5区分（標準年限内、1年、2年、3年、4年以上超過）を手入力している。丸めにより合計が100%から0.1%ずれる場合がある。
- **学位取得**：NISTEP『博士人材追跡調査 第2次報告書（NISTEP REPORT No.174）』概要図表2、2015年度博士課程修了者等コホートの修了年度末の学位取得率 **72.9%**。[原資料](https://www.nistep.go.jp/wp/wp-content/uploads/NISTEP-NR174-FullJ.pdf)。入学者からみた博士号取得確率ではない。
- **論文数**：既存の `ReferenceStats.publications`（NISTEP「第1回日本博士人材追跡調査（速報版）」図表44）。元の区分0、1、2、3～5、6～9、10～20、21以上、無回答を、0、1、2、3～5、6以上、無回答に再集計する。[原資料](https://www.nistep.go.jp/wp/wp-content/uploads/NISTEP_sokuhou1.pdf)。ゲームは**査読採択論文数**、調査は**論文発表本数**であり、定義と集計時点が一致しない。

## 比較・実装上の注意

1. ゲームの「終了時期」には、36か月／48か月で学位未取得となるルートも含まれる。一方、文科省の母集団は博士課程修了者等（満期退学を含む）であり、同一の入学者コホートではない。
2. ゲームは最大1年間延長で打ち切られる。公的統計の「2年以上超過」カテゴリはゼロと表示し、欠けている長期在籍ケースを隠さない。
3. ゲームの `cs` などの研究分野は文科省の分類と一致しないため、**参考分野をユーザーが切り替えられる**。分野の切り替えは、初期条件・乱数・100試行の結果を変更しない。
4. 実際の貯金・借入残高の比較可能な全国分布は未収集なので、ゲーム内の分布のみ表示する。
5. 研究成果の実統計とゲームモデルの採択率を統合して、個人の全国順位や実際の学位取得確率を算出しない。

実測スナップショットの更新には一次資料・調査年・母集団・定義を再検証し、`src/real-world-comparison.js` と `tests/real-world-comparison.test.cjs` を更新する。
